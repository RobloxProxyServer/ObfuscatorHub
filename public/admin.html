Every action below runs immediately when clicked — there's no confirmation dialog beyond what's shown on the card itself. You're signed in for this session; Log out ends it early.

Clean Up Temp Scripts
Deletes data
Removes every document currently sitting in the temporary holding collection (scriptsave). This is normally empty within moments of a script finishing its upload to Rubis — anything still here is either mid-upload right now or permanently stuck. Running this while an upload is in progress will delete that script's temp record before it finishes.
Log Everyone Out
Affects all users
Wipes every row in the sessions collection. Every logged-in user's sid cookie stops resolving on their next request, so they're all signed out at once. This does not affect this admin session — that's a separate cookie.
Join Everyone to Discord
Safe to run anytime
Adds every saved Discord user back to the server right now, using each person's stored refresh token — nobody has to log in again. This is the same join that happens automatically on login; this button just re-runs it for everyone at once (e.g. after someone left the server).
View Script by ID
Read-only
Looks up a script by its scriptId — permanent collection first, then the temp holding collection — and pulls the real code (from Rubis, inline temp storage, or legacy GitHub), bypassing the password gate entirely.
Clean Up Dead Keys
Safe to run anytime
Removes key documents that are genuinely done: revoked more than 90 days ago, or generated but never redeemed in 90 days. Keys still counting down, still unrevoked, or explicitly set to never expire are never touched.
Migrate Stuck Temp Scripts → Rubis
Safe to run anytime
Finds any script still sitting in the temp collection without a permanent Rubis record, and uploads it now. Already-migrated scripts are skipped automatically — this is safe to run repeatedly.
Migrate Legacy GitHub Data → MongoDB
One-time / re-runnable
Pulls anything still left in the old GitHub-backed storage (script records with a fileName, and user accounts/index from the old USERDATA repo) into MongoDB. Already-migrated records are detected and skipped, so this is safe to re-run if it was interrupted. Requires GITHUB_TOKEN to be set.
